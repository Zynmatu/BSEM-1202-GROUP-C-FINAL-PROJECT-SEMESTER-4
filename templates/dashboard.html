Quick Start

🚀 Authenticate and make your first request

# 1. Obtain a JWT token curl -X POST http://localhost:8000/auth/login \ -H "Content-Type: application/json" \ -d '{"email":"admin@company.com","password":"secret"}' # 2. Use the token to list employees curl http://localhost:8000/employees/ \ -H "Authorization: Bearer <access_token>" # 3. Create a department curl -X POST http://localhost:8000/departments/ \ -H "Authorization: Bearer <access_token>" \ -H "Content-Type: application/json" \ -d '{"name":"Engineering","description":"Product Dev"}'
